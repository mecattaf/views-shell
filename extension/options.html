Connection

This extension reaches views-shell through Chrome native messaging. Chrome starts the host when a page connects, and only because the host's manifest names this extension () in allowed_origins. Nothing listens on a port, and there is nothing to pair.

The manifest lives in ~/.config/google-chrome/NativeMessagingHosts/ (Chromium: ~/.config/chromium/NativeMessagingHosts/). Print it with views-shell native-host --manifest; on NixOS, Home Manager writes it.
