# views-shell, chapter 1: a content-free Views program runs on stock scroll, and the unknowns are measured

Status: ratified (Tom, 2026-10-01: "in the next 3-4 hours, you will use the conwip factory to completely resolve the unknowns (code durably, not just for a spike)")
Repos: mecattaf/views-shell (primary, public)
Consumers: Tom (daily-drives `main` on scroll later), the factory
Inputs: `README.md`, `docs/rules.md`, `docs/architecture.md`, `shell/` (the lifted code and sketches), `tools/bench/` (the bench scripts), `identity.json`
Findings: F1 (2026-10-01, measured on the bench): at 154.0.8037.92 `//ui/views` → `//ui/accessibility/platform` → `//gin` → `//v8` under the default `enable_extensions = true` (`ui/accessibility/platform/BUILD.gn`, the Automation API bindings); `enable_extensions = false` is not an option (`ui/webui/webui_features.gni` asserts `enable_extensions_core`), so `shell/patches/views-shell-ax-automation-bindings.patch` (7 lines) puts that block behind a new arg `enable_ax_automation_bindings`, default unchanged, and the bench sets it false. `libv8.so` in the component build is 194 MB on disk.
Bench: one headless NixOS build host reached as `worker` over ssh, Chromium checkout `~/chromium/src` at tag `154.0.8037.92` (the newest Chrome stable on 2026-10-01), build directories `out/views` (component) and `out/release` (non-component), stock scroll at `~/views-bench/scroll`, the FHS build environment at `~/views-bench/build-env`, `runtime-test` at `~/.local/bin/runtime-test`

## Outcome
Today the repository is a foundation: schemas, docs, a kit inventory, an extension skeleton and a lift of earlier prototype code that has never been compiled in this tree. Nothing runs. When this chapter closes, the bench holds Chromium 154.0.8037.92 with a content-free `views_examples` built and running as a client of headless stock scroll; `//views_shell:views_shell`, a Views program with `assert_no_deps` on `//content`, the Blink renderer, `//v8`, `//chrome`, `//ash` and `//chromeos`, builds in the same tree and draws a bar on a `zwlr_layer_surface_v1` surface with an `xdg_popup` child; its idle footprint is measured beside `views_examples` under the same headless harness; the scroll adapter switches a workspace over the i3 socket and observes the echo; the user configuration has a schema sized for `chrome.storage.sync`, with a probe page and a written two-seat procedure that settles whether an unpacked extension with a pinned key syncs; the lessons of the first prototype are written down; the All Black Chrome theme is expressed as a theme directory; and the docs no longer speak of a scroll fork, a patch queue or Agency contracts.
